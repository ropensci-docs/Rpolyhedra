# loggerSetupFile

loggerSetupFile

## Usage

``` r
loggerSetupFile(log.file, default.threshold = "info", append = TRUE)
```

## Arguments

- log.file:

  log path for logging file

- default.threshold:

  threshold for setting root. Default = "info"

- append:

  if set to FALSE, cleanup all previous logs
